# 규칙 탐지 문장 교체 실험 B

## 완료 범위

원본 audit, KLUE 재학습 seeds 13·42·100, KoELECTRA seed 42의
테스트 추론·사례 단위 집계·주요 지표 검산을 완료했다.
기존 전문가 평가 및 132건 subset과 구분되는 별도 실험이다.

공통 recipient-target 집합:
벌금 68건, 징역 215건, 금고 5건.
동일·다른 라벨 donor를 각 10회 대응 추출했다.
금고는 탐색적으로 보고한다.

## 코드 범위

- `src/kljpaudit/cue_swap.py`: 행동 지표·paired CI·성능 점추정치.
- `scripts/reproduce_cue_swap_B.py`: 확정된 비공개 연결표·확률에서 재계산.
- `tests/test_cue_swap.py`: 명시적 합성 배열 테스트.
- `results/aggregate/cue_swap_B_*.csv`: 검산된 집계 결과.
- `docs/manuscript_cue_swap_B.tex`: 영어 논문 삽입 초안과 표.

이번 공개 모듈은 donor 선정과 모델 추론을 다시 수행하지 않는다.
성능 CI 및 3 seeds 요약 전체를 생성하는 종단간 파이프라인이라고
표현하지 않는다. 해당 결과는 검산된 집계표로 함께 제공한다.

## 실행

저장소 루트에서 실행한다.
준비 자료와 추론 결과 및 새 출력 폴더는 저장소 밖에 둔다.

```bash
PYTHONPATH=src python scripts/reproduce_cue_swap_B.py \
  --preparation /비공개/테스트준비폴더 \
  --inference /비공개/모델추론폴더 \
  --output /비공개/새재계산폴더

## 지표 정의

확률 비교는 동일 라벨·다른 라벨 조건 모두,
해당 반복의 다른 라벨 donor 라벨을 기준으로 한다.

신규 donor 전이는 원본 예측이 donor 라벨과 다른 반복만 분모에 포함한다.
분모가 seed에 따라 달라 이 지표의 3 seeds 평균은 만들지 않는다.
교체 성능은 반복별 전체 라벨 공간 Macro-F1·joint EM을 계산한 뒤 평균한다.

## 주요 결과

징역 target flip의 다른 라벨 교체 − 동일 라벨 교체 차이는
재학습 3 seeds 평균 +3.66 pp, 명목 95% CI [1.61, 6.14] pp다.
donor 방향 확률 차이는 +0.332 pp, CI [-0.047, 0.876] pp다.

이는 징역 예측의 교체 민감성을 보강하지만,
donor 라벨을 일관되게 따라간다는 근거는 제한적이다.

## 한계

규칙 탐지 C는 전문가 검증 누출 문장과 동일하다고 가정하지 않는다.
교체 문서는 법적으로 타당한 반사실 사례로 검증되지 않았다.
CI는 확정된 donor 계획에 조건부이며 공유 donor 의존성을 완전히 반영하지 않는다.
명목 95% CI이며 다중 비교 보정은 하지 않았다.
seed 평균 CI는 관측한 세 seed에 조건부다.

## 논문 반영

기존 삭제 결과 뒤에 별도 하위절로 추가한다.
기존 132건 전문가 검증 분석을 교체하거나 동일 집합으로 설명하지 않는다.
초록에는 새 결과를 넣더라도 donor 라벨 추종 또는 인과적 누출 입증으로
강화하지 않는다. 표 번호는 논문 소스에서 자동 부여한다.
